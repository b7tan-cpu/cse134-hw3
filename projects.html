Project Concepts

These two proposals describe what I would build next. They are not completed projects; tools, features, and outcomes below are plans.

Study Compass

Problem: Students often track deadlines across several course pages and notes.

Idea: Bring upcoming tasks into one small dashboard, grouped by course and due date.

Proposed features

  • Add a task with a course, due date, and estimated effort.
  • View a weekly list of upcoming work.
  • Mark tasks complete and review remaining work.

Development plan

  1. Build a semantic HTML task list and input form.
  2. Add CSS for readable views on phones and computers.
  3. Add JavaScript and browser storage in a later version.

Planned tools: HTML, CSS, JavaScript, and localStorage.

My planned role: Information architecture, interface implementation, and accessibility checks.

Learning goal: Understand form validation and storing structured data without a backend.

Repository and live demo: not available yet.

Campus Resource Finder

Problem: Helpful campus information can be scattered across separate websites.

Idea: Create a concise directory for study spaces, tutoring, and student support.

Proposed features

  • Browse resources by category.
  • Search resource names and descriptions.
  • Read accessibility notes and follow official source links.

Development plan

  1. Collect and verify a small set of official resources.
  2. Build semantic resource articles.
  3. Add filters after the static directory is complete.

Planned tools: HTML, CSS, JavaScript, and a small JSON dataset.

My planned role: Content organization, implementation, and source verification.

Learning goal: Practice data-driven rendering and keyboard-accessible filtering.

Repository and live demo: not available yet.
